                                                                                      OTT Streaming Platform

A company wants to create an OTT streaming platform where users can watch movies
offering a smooth viewing experience with strong admin and user features.
Admin Functions
1. Authentication
● Admin should be able to login with email and password.
● Logged in admin should be able to change his account’s password
2. Content Management
● Logged in admin should be able to see list of movies for easy
management
● Logged in admin should be able to Create/Edit/View details of/Delete a
movie
● All movies will have a title and description
3. User Management
● Logged in admin should be able to see list of users for easy management
● Logged in admin should be able to Search and block/unblock users.
● Logged in admin should be able to see view history of users
4. Reports
● Logged in admin should be able to see the view count of each movie
ordered by view count from high to low.

User Functions
1. User Authentication and Account Management
○ Users should be able to register and login using their email and password.
2. Browsing and Viewing Content
○ Logged in Users should be able to browse movies for viewing.
○ Each movie should display a title, description and movie thumbnail.
○ Logged in Users should be able to view full movies.
3. User Account Features
○ User should be able to change their own password
4. Interaction and Engagement
○ Users should have the ability to add/remove content to their watchlist for
later viewing.
○ Users should be able to view their watch history.
